Fonctionnement

Une architecture décentralisée pour une vision centralisée

  1. Saisie locale

    L'utilisateur saisit les données sur son application STELab, même sans connexion Internet.

  2. Disponibilité terrain

    Les informations restent accessibles et modifiables sur le poste de l'utilisateur.

  3. Synchronisation

    Dès que la connexion revient, les données rejoignent automatiquement le serveur central sécurisé.

  4. Pilotage

    Les niveaux district, régional et central consultent les données consolidées selon leurs droits d'accès.
